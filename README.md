# ost-legal

`Presub` (미리자막 — 온디바이스 영상 자막 번역, iOS) 의 개인정보처리방침·지원 페이지. GitHub Pages 로 정적 서빙한다.

| 파일 | 용도 | App Store Connect 필드 |
|---|---|---|
| `privacy-policy.html` | 개인정보처리방침 (ko·en·ja·zh-Hant) | 앱 정보 → 개인정보 처리방침 URL |
| `support.html` | 지원 페이지 · FAQ | 버전 정보 → 지원 URL |
| `press.html` + `press/` | 프레스 킷 (ko·en·ja·zh-Hant) · 아이콘·스크린샷·데모 영상(NASA 퍼블릭 도메인 소재) | — (홍보·기자 문의용) |

- 서버를 두지 않는다. 폰트 파일·웹폰트 링크를 넣지 않는다(시스템 폰트 스택만).
- 앱 이름이나 기능이 바뀌면 이 저장소도 같이 고친다 — 스토어 메타·앱 문구·이 페이지가 어긋나면 심사에서 지적된다.
- 원본은 본체 저장소 `docs/legal/` 이다. 여기서 직접 고치지 말고 원본을 고쳐 복사한다
- 본체 저장소: 비공개 `aucus/ondevice-subtitle`
